## 🎯 Overview

Step-by-step diagnostic wizard for tattoo machine and power supply faults. Identify the cause, PSU, clip cord, machine, pedal, or technique.

**Category:** Studio Operations

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/) - a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **Tattoo Machine Not Working**
- ✅ **Power Supply Troubleshoot**
- ✅ **Tattoo Machine Fault Diagnosis**
- ✅ **Coil Machine Problems**
- ✅ **Rotary Machine Not Starting**
- ✅ **Responsive Design** - works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/power-supply-troubleshooter/](https://poliinternational.com/tools/power-supply-troubleshooter/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS - no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/power-supply-troubleshooter.git
cd power-supply-troubleshooter
# open index.html in your browser
```
